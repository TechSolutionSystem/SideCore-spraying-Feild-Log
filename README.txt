SideCore Spraying PWA

This package must be served over HTTPS for full iPhone/Android app behaviour.

Recommended:
1. Upload the contents of this folder to any static HTTPS host:
   - GitHub Pages
   - Cloudflare Pages
   - Netlify
2. Open the HTTPS link once on the phone.
3. iPhone: Safari > Share > Add to Home Screen.
   Android: Chrome > menu > Add to Home screen / Install app.
4. After first load, the app can work offline.

SEND uses the native phone share sheet.
The draft is saved locally until sharing completes.
